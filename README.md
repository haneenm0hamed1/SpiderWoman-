# 🕸️ Spider-Woman UI Challenge

A high-end, interactive web experience inspired by the Spider-Verse, featuring a magic lens effect and dynamic theme switching.

## ✨ Features
- **Magic Blob Cursor:** A custom lens that reveals a parallel universe (The Rival) as you move.
- **Dynamic Theme Switch:** Toggle between Gwen (Ghost Spider) and her Rival with smooth transitions.
- **Modern Tech Stack:** Built with React, Vite, Framer Motion, and Tailwind CSS v4.
- **Responsive Design:** Fully optimized for mobile with touch-ready interactions.

## 🚀 Tech Stack
- **Framework:** React + Vite
- **Styling:** Tailwind CSS v4 + OKLCH Color Space
- **Animations:** Framer Motion
